📊 Sales Data Analysis & BI Dashboard
🚀 Project Highlights
An end-to-end data pipeline transforming raw sales records into actionable business insights.

Extraction: Structured and queried transactional data using MySQL.

Cleaning: Used Python (Pandas) to handle missing values, standardize formats, and remove outliers.

Visualization: Developed an interactive Power BI dashboard to track revenue, profit margins, and regional performance.

🛠️ Tech Stack
Database: MySQL

Programming: Python (Pandas, NumPy)

BI Tool: Power BI (DAX, Power Query)

📈 Key Insights
Identified top-performing regions and high-margin product categories.

Discovered seasonal sales trends to optimize inventory management.

Automated reporting workflow, saving hours of manual data processing.

📁 Repository Contents
SQL_Queries.sql: Data extraction logic.

sales.ipynb: Python data cleaning script.

sales.pbix: Interactive Power BI dashboard.
